# Problem Statements

## Problem Statement 1
Netflix users need a faster way to discover relevant content because the large content library can make decision-making overwhelming.
*(Primary persona: The Binge Watcher)*

## Problem Statement 2
Casual viewers need quick, personalized recommendations because they have limited time and don't want to spend several minutes browsing.
*(Primary persona: The Casual Viewer)*

## Problem Statement 3
Users who enjoy discovering new genres need better search and filtering options because standard categories may not always help them find niche content.
*(Primary persona: The Explorer)*
