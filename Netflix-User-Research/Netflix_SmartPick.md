# Design Opportunity: Netflix SmartPick

A personalized discovery system that helps users decide what to watch quickly, directly addressing all three problem statements.

## How It Works
When a user is undecided, SmartPick asks a few quick questions, then returns a small number of tightly personalized recommendations — instead of another endless row.

### 🎭 Mood
Happy · Relaxing · Exciting · Emotional · Scary

### ⏱ Time Available
10–30 minutes · 30–60 minutes · 1–2 hours · Multiple episodes

### 🎬 Content Type
Movie · Series · Documentary · Anime

### 🌎 Language
English · Hindi · Korean · Spanish · etc.

## Why It Works
| Problem Statement | How SmartPick Helps |
|---|---|
| Choice overload (Binge Watcher) | Narrows the library to a handful of relevant picks instead of full rows |
| Limited time (Casual Viewer) | "Time Available" filter matches content to the exact window a user has |
| Niche discovery (Explorer) | Language + genre + mood combination surfaces content standard categories miss |

## Next Steps for Validation
1. Prototype the SmartPick flow (4 quick-tap questions → 3-5 recommendations)
2. Usability-test against the current browsing experience with real users
3. Measure: time-to-decision, session completion rate, post-watch satisfaction
