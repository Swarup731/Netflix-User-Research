# Empathy Map — "The Explorer"

**Says**
> "I want to find something different, not just the same trending titles everyone else is watching."

**Thinks**
- There's probably a great niche show I'm missing.
- Search should let me combine what I want (language + genre + actor).
- Standard categories feel too broad for what I'm looking for.

**Does**
- Uses search actively rather than browsing rows
- Looks up specific actors/directors
- Filters by language when possible
- Explores international and independent titles

**Feels**
- Curious and exploratory
- Mildly frustrated when search results feel too generic
- Rewarded when they find a great hidden gem
