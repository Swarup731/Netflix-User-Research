# Research Objectives — Netflix

## App
**Netflix** — Video Streaming Application

## Research Objective
To understand how users discover, select, watch, and manage content on Netflix, and identify pain points related to content discovery, recommendations, pricing, interface, and viewing experience.

## Target Users

| Parameter | Target |
|---|---|
| Age | 18–35 |
| Users | Netflix subscribers |
| Device | Smartphone, laptop, Smart TV |
| Usage | Regular/occasional streaming |
| Location | India |
| Sample size | 8–12 users |
| Method | User interviews |
| Duration | 10–15 minutes |

## Key Research Areas
- Content discovery
- Recommendation system
- Search experience
- User interface
- Subscription/pricing perception
- Watchlist usage
- Notifications
- Streaming experience
- Multiple profiles
- Overall satisfaction

## ⚠️ Note on Data in This Repository
The interview data, findings, empathy maps, and personas in this repository are **synthesized examples** built to demonstrate the full research-to-persona pipeline (in the style of realistic transcripts), not results from actual conducted interviews. Before treating this as a real research deliverable:
1. Recruit 8–12 real Netflix users matching the table above.
2. Run the interview script in `Interview_Questionnaire.md`.
3. Replace `Interview_Data.xlsx`, `Research_Findings.md`, the empathy maps, and the personas with your real results.
