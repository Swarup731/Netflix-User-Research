# Typography

## Fonts
- **Primary:** Inter
- **Alternative:** Arial / Helvetica

## Scale

| Element | Desktop | Mobile | Weight |
|---|---|---|---|
| Display | 48px | 32px | Bold |
| H1 | 36px | 28px | Bold |
| H2 | 28px | 24px | Semi-Bold |
| H3 | 22px | 20px | Semi-Bold |
| Body Large | 18px | 16px | Regular |
| Body | 16px | 14px | Regular |
| Caption | 14px | 12px | Regular |
| Button | 16px | 16px | Medium |

## Usage
- **Display** — hero title on Movie Details / featured content banners
- **H1** — page/screen titles ("Search", "My Netflix")
- **H2** — section/row headers ("Trending Now", "Continue Watching")
- **H3** — card titles, modal headers
- **Body Large** — lead paragraph / synopsis text
- **Body** — default UI copy
- **Caption** — metadata, timestamps, legal text
- **Button** — all button labels, consistent across breakpoints (doesn't scale down like other elements, since tap targets need to stay legible)
