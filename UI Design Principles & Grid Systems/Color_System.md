# Netflix UX Redesign – Color System

## Primary Colors

| Color | Hex | Usage |
|---|---|---|
| Primary Red | `#E50914` | Primary CTA buttons, highlights |
| Background Black | `#141414` | Main application background |
| Surface Dark | `#221F1F` | Cards and containers |

## Text Colors

| Color | Hex | Usage |
|---|---|---|
| Primary Text | `#FFFFFF` | Headings and important text |
| Secondary Text | `#B3B3B3` | Descriptions and metadata |

## State Colors

| Color | Hex | Usage |
|---|---|---|
| Success | `#46D369` | Success indicators (e.g. "Downloaded") |
| Focus / Interactive | `#FFFFFF` | Focus rings / interactive outline states |

## Notes
- This palette is used consistently across every mockup in `../High_Fidelity_Mockups/` and every wireframe in `../Wireframes/`.
- **All combinations above are verified against WCAG 2.1 contrast thresholds in `../Accessibility/WCAG_Contrast.md`** — actual computed ratios, not estimates. One combination required a follow-up rule (see that file) rather than a color change.
- Visual swatches: `color-swatch.png` in this folder.
